# Final laptop artifact preservation

This directory contains the useful remaining human-readable artifacts
identified during the final WSL -> GitHub migration.

Preserved:
- small logs
- diagnostic reports
- checksums
- scripts
- configuration/evidence files

Intentionally NOT preserved here:
- generated bzImage/vmlinux
- ISOs
- Linux source archives
- build products
- temporary test directories
- large/redundant commit dumps
- generated local `.config`
- files already preserved in docs/research/2026-09-10/

The Linux 7.2.2 source tree remains tracked separately.
