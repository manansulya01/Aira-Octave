# Developer Guide

## Layout
- `linux-7.2.2/` kernel (do not modify without need; canonical config in configs/).
- `initramfs/` guest root source; `gui/` X session sources (shell, no compile); `rootfs/` staging (generated by build-gui.sh from Ubuntu debs via curl, no sudo).
- `scripts/` automation (all bash, exit codes, logs).

## Workflows
- Change userspace: edit initramfs/ or gui/, run build-initramfs.sh and/or build-gui.sh + build-rootfs.sh, then test-kernel.sh / test-gui.sh.
- Add package: dir with PKGINFO + files, `airapkg build`.
- Add service: /etc/aira/services/X.conf (CMD/DEPS), test via aira-init start/status.
- Debug boot: check logs/final-completion/*/last*.log markers (Linux version, Run /init, userspace ready, GUEST AUTOTEST PASS, GUI TEST PASS).

## Cross-dev
Guest arch = host arch (x86_64); Ubuntu-deb binaries run unmodified. No toolchain in guest v1 (use host gcc + copy). GUI needs no compilation (shell + deb packaging).
